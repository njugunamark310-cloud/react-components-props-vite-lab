React Blog Site

About

This is a React lab from Moringa School. The task was to build a simple blog site using React components and props.

What I Practiced

Creating React components.

Passing data using props.

Using default prop values.

Rendering lists using .map().

Using keys when rendering lists.

Styling with Tailwind CSS.

Components

App – Main component.

Header – Displays the blog name.

About – Displays the blog image and description.

ArticleList – Displays a list of blog posts.

Article – Displays an individual blog post.

Technologies

React

JavaScript

Tailwind CSS

Vite

How to Run

Clone the repository:

git clone git@github.com:njugunamark310-cloud/react-components-props-vite-lab.git

Navigate into the project:

cd react-components-props-vite-lab

Install dependencies:

npm install

Start the app:

npm run dev

Running Tests

npm test -- --run
